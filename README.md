🏏 IPL 2020 Interactive Dashboard
An elegant and fully interactive dashboard showcasing team and player performances from the IPL 2020 season — built using R Shiny, Plotly, and dplyr.

Explore match-level insights, player stats, and team trends with visually engaging charts and real-time inputs.
Ideal for data analysts, cricket fans, and sports enthusiasts looking to deep-dive into IPL 2020.

🚀 Key Features
📊 Total Runs & Wickets Overview

🏏 Top 10 Batsmen & Bowlers by performance

🧮 Team-wise Performance Analysis

📈 Dynamic Charts: Line plots, Pie charts, Histograms

🔍 Player-Specific Stats with real-time filters

💡 Tech Stack
R Shiny – For interactive UI & server-side logic

Plotly – For rich, interactive visualizations

dplyr – For efficient data manipulation
